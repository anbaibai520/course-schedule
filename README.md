# course-schedule

个人课程表网页（周视图 / 日视图 / 列表视图 + 多人课表叠加对比 + 天气 + 课程编辑器）。

单文件、零依赖、纯前端。所有课程数据保存在浏览器 localStorage 中，不会上传到任何服务器。

## 本地使用

直接用浏览器打开 `index.html` 即可。

## 在线地址

GitHub Pages（部署后填写）：`https://<用户名>.github.io/course-schedule/`

## 数据说明

- 课程数据 key：`course-schedule-v1`
- 天气缓存 key：`course-weather-v1`

换设备 / 换浏览器数据不互通，可用页面内的「导出 / 导入 JSON」功能迁移。
